# طراحی دیتابیس

## جداول:
- **Users**: ذخیره اطلاعات کاربران (نام، ایمیل، رمز عبور)
- **Products**: ذخیره اطلاعات محصولات (نام، توضیحات، قیمت، تصویر)
- **Orders**: ذخیره سفارشات (کاربر، محصولات خریداری شده، وضعیت)
- **Cart**: ذخیره سبد خرید (کاربر، محصولات، تعداد)

## ارتباطات:
- یک کاربر می‌تواند چندین سفارش داشته باشد.
- هر سفارش می‌تواند چندین محصول داشته باشد.
