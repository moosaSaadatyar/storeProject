# Angular Shop

این پروژه یک فروشگاه آنلاین است که با استفاده از Angular در فرانت‌اند و NestJS در بک‌اند پیاده‌سازی خواهد شد.

## ویژگی‌ها
- نمایش لیست محصولات
- جستجو و فیلتر محصولات
- سبد خرید
- پرداخت آنلاین
- ثبت‌نام و ورود کاربران

## ساختار پروژه
- **Frontend**: Angular
- **Backend**: NestJS
- **Database**: PostgreSQL

## مراحل آینده
1. طراحی UI و UX
2. ساخت API‌ها با NestJS
3. پیاده‌سازی فرانت‌اند با Angular
4. راه‌اندازی سیستم پرداخت
